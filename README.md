# Riad Fitness Website

A responsive static coaching website for Riad Fitness.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and form placeholder
- `assets/images/` — upload your real photos here
- `.github/workflows/deploy.yml` — automatic GitHub Pages deployment

## Add your photos
Replace these files with your own images:
- `hero.jpg`
- `about.jpg`
- `result-01.jpg`
- `result-02.jpg`
- `result-03.jpg`

Keep the filenames the same and the website will use them once the HTML image areas are converted to actual `<img>` elements.

## Important before publishing
Replace placeholder claims marked with `*` with your exact verified certification and experience details.
Connect the application form to your preferred form/email service before using it with real clients.

## GitHub Pages
GitHub Pages can publish static HTML/CSS/JS directly from a repository. For a user site, the repository can be named `<username>.github.io`.
